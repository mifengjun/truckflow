# 正式系统开发验收

日期：2026-10-04。范围：美国 LTL 人工报价、人工下单与预付订单首版；开发环境，尚未发布 Vercel。

## 交付范围

正式入口 `/login`，客户 `/portal`，后台 `/admin`；原型 `/prototype` 独立保留。正式页面沿用已确认的组件与视觉，读取真实 Cookie 会话、API 和数据库。入口按当前角色跳转，导航按权限显示；服务端独立核对数据库中的账号状态、角色与公司范围。

客户公司和资金账户建立、邀请与重发密码设置邮件、地址新增与版本化编辑、分步询价、人工报价草稿与发布、报价比较、独立订单确认、私有转账凭证与充值申请、实际到账核验、资金流水、订单审核/结果回填、运输进度、BOL/POD/其他文件上传及授权下载均已实现。冻结客户可禁止新业务，已有订单与资金处理按状态继续。

客户下单只提交报价 ID 与幂等标识。服务端重查已发布报价及有效期、客户状态与可用余额，保存运输与销售价格快照，并在同一事务创建订单、冻结及流水。成本独立存储，客户接口不返回。

## 资金与状态证据

- 重复充值核验只入账一次；银行实际到账参考号有唯一约束。
- 余额不足不生成半成品订单；并发订单不能超占可用余额。
- 相同幂等标识返回原订单；不同报价复用标识报冲突。
- 提交冻结；已确认承运商接单扣款；确认未生成外部订单的拒单解冻；结果未知保持冻结并禁止盲目重试。
- 已拒单重试重新检查原报价有效期和余额、重新冻结；处理版本冲突要求刷新。
- 履约按提货、运输、送达顺序推进，拒绝跳过节点；余额与冻结金额等于不可重复流水的累计变动。

浏览器实测开发资料：充值 1,000 USD，报价 360 USD；订单提交后余额 1,000、冻结 360、可用 640；结果未知仍冻结；接单后余额 640、冻结 0、可用 640。已顺序更新到送达，并上传私有 BOL；地址簿新增和编辑也通过浏览器验证。以上均为明确标注的 TEST 模拟记录，不代表实际到账或承运商订单。

## 架构与安全边界

私有 `app` schema 不向 anonymous/authenticated 开放。受限 `truckflow_runtime` 可以按 RLS 策略跨公司处理业务，实际用户权限由服务层执行；不把该角色的 RLS 描述成用户级隔离。迁移角色和运行角色分开。固定 search_path 的私有辅助函数仅运行角色可调用，未开放 Auth 表直接查询。

所有资金操作使用数据库事务和账户行锁；订单/充值使用状态及版本检查；流水和审计不对运行角色开放更新或删除。文件存储私有，上传最大 3 MB，仅 PDF/PNG/JPEG，授权链接有效期 60 秒。

Supabase security advisor 仅提示泄露密码检测未启用；业务表未出现安全提醒。外键覆盖索引提醒已处理。unused index 是新建库和少量测试下的 INFO，保留队列与审计索引，不据此删除。

## 后续上线准备与范围限制

1. 配置 Vercel 项目、独立生产配置、正式域名和精确 Origin；生产运行环境不放迁移管理员连接。Session pooler 当前 `max:1`，上线前核定总连接预算。
2. 配置生产 SMTP 和 Auth 回调白名单、关闭公开注册，启用可用的泄露密码保护；从中国大陆客户网络和海外管理网络测试访问、邮件、上传下载和性能。
3. 财务收款账户、银行核验依据及实际承运商操作制度由运营配置并确认；界面没有编造收款账号。上线前用真实管理员与独立验收客户再次演练。
4. 当前订单搜索与状态筛选作用于分页后的本页，界面已明确标注；公司列表最多 100 条，询价/订单/流水每页 20 条，客户充值页面显示最近 20 条。更大规模需扩展服务端全量筛选与分页。
5. 自动承运商接口、在线支付、取消/退款、追加费、售后工单、报表、公共仓库维护及多家公司 SaaS 不在本轮人工预付闭环中；部分仍仅有原型结构。现阶段没有生产流量、真实转账、实际承运商提交或部署。

## 运行与复验

环境、角色、迁移、文件配置见《开发环境接入》。运行 `pnpm dev` 后执行 `pnpm test:integration`。集成测试只用于指定开发项目，以隔离身份和 TEST 数据验证并清理。

可选浏览器复验：`node scripts/browser-fixtures.mjs` 创建临时开发身份，账号清单仅保存到 Git 忽略的 `.env.browser-test.local`；其密码只用于可丢弃 QA 身份。完成后 `node scripts/cleanup-browser-fixtures.mjs` 按保存的精确 ID 及 TEST 公司标记清理。脚本拒绝生产环境及非本地 Origin；清理前核对 TEST 公司及临时 QA 邮箱和姓名。集成配置同样拒绝生产环境，已验证该保护在启动阶段阻止测试。
