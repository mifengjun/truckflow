## 一、卡派概述

### 1.1 什么是卡派

**卡派（卡车派送）** 是指货物通过海运或空运抵达目的国港口/机场并完成清关后，由本地卡车公司负责从港口提柜，将整柜或拼箱货物运送到指定的海外仓、亚马逊 FBA 仓库或私人地址的**尾程运输**方式。

### 1.2 卡派的市场地位

- 全球货运卡车市场在 2020 年增长至 **2.1 万亿美元**，预计 2026 年达到 **2.7 万亿美元**，占所有运输方式总收入的**八成以上**。
- 北美货运承载量约 **65%** 由卡车完成。
- 相较快递（UPS、FedEx 等），卡派在**价格和时效**上对大件、重货更有优势。

### 1.3 卡派与快递的主要区别

| 对比项 | 卡派（FTL/LTL） | 快递（UPS/FedEx 等） |
|--------|----------------|---------------------|
| 适用货量 | 大件、重货、多托盘 | 小件包裹（通常 < 70 磅） |
| 计费方式 | 按重量、体积、密度等级 | 按体积重量（长×宽×高÷139） |
| 时效 | 1-5 天（FTL 更快） | 2-7 天 |
| 成本 | 大货更划算 | 小件更便宜 |
| 装卸 | 需叉车/托盘 | 人工投递 |

## 二、美国卡派

美国卡车派送是本土地面运输的主要渠道，分为 **整车运输（FTL）** 和 **零担运输（LTL）** 两种核心方式。

### 2.1 FTL 与 LTL 对比

#### FTL（Full Truckload，整车运输）

- **定义**：货主包下整辆卡车，从装货地直达目的地，中途不拆货、不分拣、不混装。
- **适用场景**：
  - 货物能装满 **12 个标准托盘** 以上
  - 重量接近卡车最大载重（53 尺卡车最大可载约 **30,000 磅**）
  - 对时效有严格要求（旺季补货、高价值商品）
  - 温控、易碎、贵重商品
- **优势**：时效稳定、安全性高、破损率低
- **常见设备**：53' 干式厢式拖车的 8 级牵引车
- **头部承运商**：Schneider National、Knight-Swift、Landstar System、CRST International、JB Hunt

#### LTL（Less Than Truckload，零担拼车）

- **定义**：单一货主货物不足整车，与其他货主货物拼车运输，经分拨中心中转。
- **适用场景**：
  - 货物重量在 **150 - 15,000 磅** 之间
  - 少于 **10 个托盘**
  - 不着急送达，可接受 2-5 天弹性时间
  - 希望控制物流成本
- **优势**：成本低，只需为实际占用的空间/重量付费
- **劣势**：时效不稳定、多次装卸增加货损风险
- **头部承运商**：FedEx Freight、XPO Logistics、YRC Freight、ODFL（Old Dominion Freight Line）

#### 快速选择决策表

| 货物情况 | 推荐方式 |
|---------|---------|
| ≥ 12 托盘 或 接近整车载重 | FTL |
| < 10 托盘，重量 150-15,000 磅 | LTL |
| 对时效有严格要求 | FTL |
| 高价值、易损、温控商品 | FTL |
| 小批量、多批次、非紧急 | LTL |
| 单件大件超重（> 150 磅或 48 英寸） | 卡派（LTL/FTL） |
| 小件包裹（< 70 磅） | 快递 |

#### FTL 与 LTL 的四个共同点

1. 主要通过**公路**运输
2. 均使用 **8 级卡车头（Tractor）**
3. 均需持有**商业驾照（CDL）**的专业驾驶人
4. 主要装运**托盘货物**

### 2.2 LTL 七大关键要点

跨境电商卖家打交道最多的是 LTL，以下七个关键点决定了 LTL 运输的效率与成本。

#### 关键 1：LTL 货运处理流程更繁琐

- **FTL**：发货人装货→打封条/货运锁→司机直送目的地。
- **LTL**：货物在到达最终目的地前，可能在拖车和仓库中**多次装卸**。
- **影响**：搬运量增加 → 产品损坏或货运索赔风险上升。
- **对策**：正确包装和保护产品至关重要。

#### 关键 2：LTL 附加费更常见

- **FTL**：司机全程关注，附加费较宽容（三天运输中滞留 15 分钟不是大问题）。
- **LTL**：运营商需保持最佳效率，**任何导致延迟或中断的情况通常都会产生附加费**。
- **心态**：虽然附加费多，但 LTL 的**总成本仍低于 FTL**。

#### 关键 3：了解货物密度等级（Freight Class）

- **FTL**：承运商不过分关注密度等级，知道是否托盘、危险品、法定重量即可报价。
- **LTL**：**不同密度等级的价格差异巨大**，即使同路线、同托盘数，价格完全取决于货运等级。
- **标准**：所有 LTL 承运人使用 **NMFTA（国家汽车货运协会）** 标准化的货运分类系统。

#### 关键 4：货物会被重新称重

- **FTL**：装载后司机在称重站验证低于 80,000 磅法定限值，之后很少再检查。
- **LTL**：到达始发站后，承运人用**专业尺寸测量器**自动扫描托盘的重量和尺寸。若与提单不符，将**重新确定运费（Re-Class）**，导致费率变化，且每次 Re-Class 至少加收 **$100+**。

#### 关键 5：运输非直达

- **FTL**：司机提货后**直接派送**，交通可预测，到达时间可计算。
- **LTL**：很少直达，运输时间比 FTL 长。交货日期通常不保证（除非支付额外费用）。多数 LTL 运营商服务水平超过 90%，但因线路和承运商而异。

#### 关键 6：先抵达先服务（FCFS）是行业标准

- **FTL**：司机接受**确定的预约时间**。
- **LTL**：驾驶员每次行程完成多次提货/送货，两小时（或更长）的**"先抵达先服务"是行业标准**，不保证接送时间。

#### 关键 7：拖车规格略有不同

| 项目 | FTL | LTL |
|------|-----|-----|
| 拖车长度 | 53' | 53' |
| 拖车宽度 | 102" | 102" |
| 车门类型 | 旋转门（Swing Door） | 卷帘门（Roll-up Door） |
| 净空高度 | 110" | 96" |

### 2.3 货运等级 Freight Class

> 重量不直接决定运费，**Freight Class 直接决定运费**。

#### 2.3.1 核心概念

- **NMFC（National Motor Freight Classification）**：NMFTA 制定的"规则和目录"，定义货物是什么。
- **Freight Class**：根据 NMFC Code + 实际状态（重量/尺寸/密度/形态）得出的"最终算钱等级"。
- **关系**：`NMFC Code + 实际状态 → Freight Class → 决定运费`

Freight Class 本质上衡量的是：**这票货对 LTL 网络来说"有多麻烦"**。越麻烦越贵，越规则越便宜。

#### 2.3.2 18 个货运等级

从 **Class 50（最便宜）** 到 **Class 500（最贵）**，共 18 个等级。
实际操作中，Class 400 以上（超轻泡货、异形、高风险、包装严重不规范）大部分承运商拒绝运输，因此常见为 **Class 50 - Class 400** 共 13 个等级。

| 等级范围 | 说明 |
|---------|------|
| Class 50 | 高密度、易装载（如金属锭、建筑材料） |
| Class 55-92.5 | 普通密度货物 |
| Class 100-175 | 中低密度货物 |
| Class 200-300 | 低密度、异形货物 |
| Class 400+ | 超轻泡、高风险货物（多被拒运） |

#### 2.3.3 三种定级逻辑

1. **固定 Class（Fixed Class）**：NMFC 明确规定，不看尺寸密度，符合描述即写死（如金属锭、高密度工业品）。
2. **密度主导型（Density-Based，最常见）**：主要由密度（PCF）决定。
3. **规则修正型（Density + Rule Adjustments）**：先算密度，再根据可装载性、操作难度、责任风险修正。

#### 2.3.4 定级的四大核心因素

| 因素 | 说明 | 影响 |
|------|------|------|
| **密度（Density）** | 重量/体积（PCF = lbs / cubic foot） | 最重要，密度越高等级越低 |
| **可装载性（Stowability）** | 能否叠放、是否规则、是否占异形空间 | 不好叠放 → 等级上升 |
| **操作难度（Handling）** | 是否需要人工、易倒易滑、需特殊设备 | 操作越麻烦 → 等级上升 |
| **责任风险（Liability）** | 是否易碎、贵重、有损坏风险 | 风险越高 → 等级上升 |

#### 2.3.5 密度计算公式

```
体积（Cubic Foot）= 长 × 宽 × 高（inch）/ 1728
密度（PCF）= 重量（lbs）/ 体积（Cubic Foot）
```

> ⚠️ 重量必须**包含托盘重量**！

#### 2.3.6 为什么会被"反弹调整"（Re-Class）

你申报的是"理论状态"，卡司看到的是"真实状态"。一旦出现：
- 尺寸偏大
- 托盘不规整
- 散件被合并
- 实际密度下降

卡司就会重新定 Class 并反弹账单补收差价。

#### 2.3.7 常见电商产品 NMFC 参考

| 品类 | 关键点 |
|------|--------|
| **家具类** | 区分 KD（拆卸，扁平包装）vs SU（组装状态）。椅子拆开是 Class 85，组装好可能是 Class 250 |
| **汽配五金类** | 通常为重货，运费较划算 |
| **运动户外类** | 视密度定级 |
| **电子家电类** | 易碎品，等级偏高 |
| **通用百货/塑料** | 找不到具体代码时的万能备选，按密度定级 |

> 查询 NMFC 代码：https://nmfclist.com/

### 2.4 美国卡派费用构成

#### 2.4.1 主要费用项

| 费用项 | 说明 | 参考标准 |
|--------|------|---------|
| **基础运费（Base Rate）** | 按里程、重量或柜型计算 | 40 尺柜 LA→芝加哥约 $1,800 |
| **燃油附加费（Fuel Surcharge）** | 按基础运费百分比收取，每周/月更新 | 12% - 25% |
| **车架费（Chassis Fee）** | 承载集装箱的拖车底盘，按天计 | $100 - $150/天 |
| **港口操作费（THC）** | 码头装卸、移动、堆放 | $300 - $500/柜 |
| **异地提还车架费（Chassis Split Fee）** | 车架存放地与提柜码头不同 | $100 - $250/次 |

#### 2.4.2 容易忽略的附加费

| 附加费 | 说明 | 参考标准 |
|--------|------|---------|
| **港口等待费** | 港口排队提柜超时 | $80 - $150/小时（免费 1-2 小时） |
| **仓库等待费** | 仓库未准备好卸货导致司机等待 | $80 - $150/小时（免费 1-2 小时） |
| **Drop/Pick 费** | 司机送柜后开走车头，卸完再回来拉空柜 | 全额拖车费（相当于两次服务） |
| **Live Unload** | 司机现场等待卸货后直接拉走空柜 | 不产生 Drop 费，但超时产生等待费 |
| **住宅地址费** | 送到私人住宅 | $20 - $50 |
| **超长/超重费** | 单件 > 150 磅或 > 48 英寸 | $50 - $200 |
| **旺季附加费** | 黑五等旺季 | 运费上涨 15% - 25% |
| **危险品附加费** | 易碎品、危险品 | $50 - $200/票 |

#### 2.4.3 体积重量计费

运费不仅看重量，还看体积：

```
体积重量 = （长 × 宽 × 高）÷ 139
```

- 实重 vs 体积重量，**取较大值**计费。
- 按体积计费为"轻货"，按重量计费为"重货"。
- "虚胖货"（体积大重量轻）运费更贵。

### 2.5 美国卡派操作流程

```
货物抵达港口/机场
    ↓
1. 清关
    ↓
2. 提柜（专业车辆到港口/机场提取货柜）
    ↓
3. 中转分拣（运至分拣中心拆柜、分拣）
    ↓
4. 预约派送（根据目的地类型预约入仓时间）
    ↓
5. 卡车装载与派送（FTL 直达 / LTL 拼车中转）
    ↓
6. 签收与反馈（核对数量、完好度，POD 签收凭证归档）
```

#### 关键时效参考（美西）

| 路线 | 时效 |
|------|------|
| 洛杉矶港/长滩港 → 美西 FBA 仓（ONT8、LAX9 等） | 1-3 个工作日 |
| 空运到美西 + 卡派尾程 | 1-2 天（全程空卡最快 4 天签收） |
| 海运到美西 + 卡派 | 卡派 1-3 天，叠加海运时间 |

## 三、欧洲卡派

### 3.1 四类主流卡派车型

| 车型 | 特点 | 适用场景 |
|------|------|---------|
| **托盘派送** | 承接打托后的重型大件，叉车装卸，损耗低 | 家具、大型设备、批量囤货、长途调拨、仓仓流转 |
| **货车直送（厢式货车）** | 小型厢式货车点对点，单次承载有限，无中转 | 短途紧急订单、海外仓到周边 FBA 仓、本地门店补货 |
| **零担卡派（LTL）** | 拼车模式，多票货物同车中转分流 | 单次出货量不足整车的中小卖家、日常零散补货、小批量 B2B |
| **整车卡派（FTL）** | 整车只装单一客户货物，全程直达不拆分 | 大批量囤货、工厂直送门店、大型项目备货 |

### 3.2 欧洲卡派完整操作链路

#### 步骤 1：录入货物信息，获取运输方案

- 货物清关提柜、运抵海外仓后，录入重量、体积、起止地址、派送时限、是否危险品等信息。
- 系统调取本地公路运力资源，输出多条线路与费用明细。
- 商家对照预算与收货时间线上敲定渠道。

#### 步骤 2：仓库装货与标签规范核验

- 按车型标准码放货物，打托货品粘贴清晰地址标签、FBA 仓码、品类标识。
- 混装货物做好分区隔离。
- 危险品遵循欧盟 **ADR 公约**完成分类分装，合规标识完整张贴。

#### 步骤 3：干线公路转运，实时同步动态

- 车辆全程搭载 GPS，平台同步更新运输节点。
- 零担货物途经中转枢纽完成分拣分流，匹配对应支线车辆。
- 整车、厢式货车直达线路无中转。
- 异常情况（停滞、限行）实时推送。

#### 步骤 4：末端上门交付，留存签收凭证

- 司机卸货、清点货品，收件方核对签字确认。
- 拍摄签收单据 **POD（Proof of Delivery）** 留存归档。
- FBA 仓库入库：核对托盘数量、箱体完好度。
- 私人/门店收货：反馈破损、短少情况，同步上传系统。

### 3.3 不同业务的适配方案

| 业务类型 | 推荐方案 |
|---------|---------|
| **跨境电商多频订单** | 托盘 + 零担 + 厢式货车组合下单，系统批量处理，统一对账 |
| **海外仓仓配流转** | 全欧公路网络任意两点直达，系统自动匹配运力 |
| **B2B 批量供货** | 货量达整车标准用专车直达；货量偏小选拼车，固定周期补货锁定运力 |
| **紧急加急派送** | 厢式货车或整车专车，优先调度减少排队等候 |

## 四、运费差异原因与成本控制

### 4.1 运费差异的六大原因

#### 1. 目的地不同

- 美西 → 美东运费可能翻倍（LA→芝加哥约 $1,500-$1,800，LA→纽约约 $2,200-$2,600）。
- 偏远地区（阿拉斯加、夏威夷、波多黎各）加价 $80-$150。
- 美东劳动力成本高（司机时薪比美西高 $9.7），高速收费更贵（美东 $0.12/英里，是美西的 2.3 倍）。

#### 2. 运输方式选错

- 大货量用 LTL 反而因拆柜费、分拣费更贵。
- 小件选快递，大件选卡派。

#### 3. 体积重量比（虚胖货）

- 体积大重量轻的货物按体积计费，运费更高。
- 例如泡沫收纳箱运费比同类产品贵 30%。

#### 4. 隐藏费用未算清

- 燃油附加费、住宅地址费、超长超重费、旺季附加费等。

#### 5. 运费计算方式不同

- 按直线距离 vs 实际行驶路线。
- 合同价（长期合作便宜 30%）vs 现货价。

#### 6. 仓库预约和时效

- FBA 仓爆仓排队，仓储费约 $15/立方米/天。
- 白手套服务（叉车卸货）加 $50-$100。

### 4.2 成本控制建议

1. **提前规划**：旺季提前 2 个月预订，避免临时涨价。
2. **选对运输方式**：大货用 FTL，小货用 LTL，超大件用卡派。
3. **优化包装**：压缩体积，减少空箱，降低体积重量，可省 10%-25% 运费。
4. **比价多家服务商**：拆分每一项费用对比，不只看总价。
5. **问清附加费**：燃油费、住宅费、旺季费统统算进去。
6. **提前预约入仓**：避免仓库高峰期，减少等待费。
7. **选 Live Unload**：仓库有足够人力设备时，优先现场卸货，避免 Drop 费。
8. **缩短港口停留**：关注车架使用天数，减少车架费累积。
9. **考虑拼柜卡派**：货量不足整柜时分摊成本。

## 五、避坑指南与实操建议

### 5.1 Freight Class 避坑

1. 尽量压缩体积，合理打托，减少空箱。
2. 主动核对 NMFC Code，不要凭经验猜 Class。
3. 散件能打托就提前打托，被动打托 = 高风险。
4. 信息宁可保守不要侥幸，报低了只会反弹（Re-Class 每次至少 $100+）。
5. 永远算上托盘的尺寸和重量。
6. 非普货下单备注清楚（如：电动自行车含锂电池，托盘包装，非危险品，尺寸重量已申报）。

### 5.2 操作通用注意事项

- 确认卡车尺寸和最大载重是否匹配货物。
- 确认报价是否包含卸货服务（有些 LTL 报价不含卸货）。
- 确认目的地是否在承运范围内（偏远地区可能加收费用）。
- 确认是否提供追踪号和签收证明。
- 发亚马逊 FBA 需确保符合预约和标签要求，避免被拒收。

### 5.3 危险品与特殊货物

- 美国：需明确标注危险品，承运商有特殊处理流程。
- 欧洲：遵循欧盟 **ADR 公约**完成分类分装，合规标识完整张贴。
- 含锂电池货物（如电动自行车）需提前申报并说明非危险品及安全包装。
